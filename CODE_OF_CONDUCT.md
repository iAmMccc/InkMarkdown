# Code of Conduct

InkMarkdown welcomes technical discussion that is respectful, specific, and focused on improving the library.

## Expected behavior

- Assume good faith while checking claims against code, documentation, and reproducible evidence.
- Explain disagreements with concrete technical reasoning.
- Respect different experience levels, languages, identities, and working styles.
- Keep examples, logs, and review comments relevant to the project.

## Unacceptable behavior

- Harassment, threats, discrimination, or personal attacks.
- Publishing another person's private information.
- Deliberate disruption, impersonation, spam, or abusive automation.
- Misrepresenting test results, security status, authorship, or project decisions.

## Scope

This standard applies to project issues, pull requests, reviews, documentation, example code, and other project-hosted collaboration spaces.

## Reporting concerns

The project does not currently publish a confidential conduct-reporting route. This document defines behavior expectations but does not claim that confidential incident intake is operational. Do not publish incident details, private information, or retaliation-sensitive context in a public issue. A non-sensitive public issue may only ask the maintainer to establish a private route.

## Enforcement

Project maintainers may moderate conduct visible in public project spaces. Confidential reports cannot be accepted safely until the maintainer establishes and documents a working private route. Any moderation action should be proportionate to the behavior and its impact on the project community.
