# Code of Conduct

InkMarkdown welcomes technical discussion that is respectful, specific, and focused on improving the library.

## Expected behavior

- Assume good faith while checking claims against code, documentation, and reproducible evidence.
- Explain disagreements with concrete technical reasoning.
- Respect different experience levels, languages, identities, and working styles.
- Keep examples, logs, and review comments relevant to the project.

## Unacceptable behavior

- Harassment, threats, discrimination, or personal attacks.
- Publishing another person's private information.
- Deliberate disruption, impersonation, spam, or abusive automation.
- Misrepresenting test results, security status, authorship, or project decisions.

## Scope

This standard applies to project issues, pull requests, reviews, documentation, example code, and other project-hosted collaboration spaces.

## Reporting concerns

For conduct concerns, use a private reporting channel provided by the repository host or project maintainers when one is available. Do not publish sensitive details in a public issue. If no private route is available, use a non-sensitive issue only to ask where a conduct concern can be reported.

## Enforcement

Project maintainers may remove content, close discussions, or restrict participation when behavior violates this standard. Actions should be proportionate to the behavior and its impact on the project community.
