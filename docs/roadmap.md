# 路线图

当前实现与未验收项以 [当前状态](current-status.md) 为准。本页只描述后续方向，不充当发布或实施授权。

## v0.0.2

以现有 UIKit-first engine、独立 SwiftUI adapter 和五个 product 为候选边界，完成 [发布清单](release-checklist.md)：最低平台运行、iPad 布局、可访问性、真机性能、消费者集成和同一候选的远端 CI。图片后端按 ADR-012 提供破坏式迁移说明。

## 后续版本

- 在现有语义契约与可复现性能基线基础上评估 InkIR；不在 v0.0.2 增加第二套渲染中间层。
- 围绕实际消费者需求扩展转换与自定义块能力，避免让 parser、handler 与 adapter 重复承担同一职责。
- TextKit 2 或其他解析/差异算法先以具体问题和可比较测量验证价值，不预设收益百分比，也不提前承诺平台范围。

新方向涉及公共契约或平台变化时先明确决策与验收条件；普通修复遵循现有约束。
