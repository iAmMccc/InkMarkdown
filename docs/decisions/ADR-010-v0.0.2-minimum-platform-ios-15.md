# ADR-010：v0.0.2 最低平台升级为 iOS / iPadOS 15

## Status

Accepted

## Date

2026-09-04

## Context and Decision

ADR-008 原定 v0.0.2 支持 iOS / iPadOS 14。SwiftUI adapter 的尺寸协商、系统 API 可用性与验证矩阵因此需要维持额外的 iOS 14 分支，而项目尚无 iOS 14 runtime 验证证据。v0.0.2 将最低部署目标提升为 iOS / iPadOS 15，并继续排除其他 Apple 平台，以减少未验证的兼容面；该决定补充 ADR-008，不改变 UIKit-first engine、独立 SwiftUI adapter product 或 Block Presentation Continuity 的架构方向。

## Consequences

- `Package.swift`、consumer fixture、ExampleApp、CI/开发文档统一使用 15.0 deployment target。
- iOS / iPadOS 14 不再属于 v0.0.2 支持范围；已发布 `0.0.1` 的兼容性按该版本 manifest 判断。
- iOS / iPadOS 15 runtime 仍须实测；较新 Simulator 编译与测试不能替代最低版本证据。
- iOS 15 继续使用 UIKit intrinsic-size 协商路径；iOS 16+ 可使用较新的 SwiftUI measurement entry point。
- iOS 15 已提供的 API 直接使用，不再保留仅服务 iOS 14 的 availability 分支；例如 display link 直接配置 `preferredFrameRateRange`。
- 显示尺寸与 scale 从当前 view、window 或前台 `UIWindowScene` 解析，不使用全局 `UIScreen.main`。iOS 16 / 17 availability 分支仅保留真实 API 能力差异。
