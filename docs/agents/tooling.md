# 工具与验证

只阅读当前任务对应的部分。以下是首选路径，不是每次任务都要执行的初始化清单。

## 查询代码

符号、调用链与引用优先 Serena。首次使用时调用其初始化说明，确认项目，再做符号和引用查询。文档、配置、字符串字面量直接使用 `rg` 或文件读取。符号结果不足时补搜；工具不可用时说明一次并用可用工具继续。

## 查询官方知识

Apple API 的签名、可用性和废弃状态优先 apple-docs，核对 iOS / iPadOS 15 边界。其他第三方库文档优先 Context7。调用方式来自当前工具 schema，不照搬旧工具名。

文档 MCP 不可用时使用官方文档网页；记录来源与未确认事实。无需为了普通查询先安装或重新注册整套 MCP。

## 构建、测试、Simulator

优先 XcodeBuildMCP 发现项目、scheme 和可用 destination，再执行所需检查。不要写死本机 Simulator UUID。

MCP 未暴露时，用 `command -v xcodebuildmcp` 和可用的 `xcodebuildmcp --version` 区分未安装与未加载。可使用已安装 CLI；仍不可用时说明原因，回退 `xcodebuild` / `xcrun simctl` 并动态发现 destination。只有任务本身要求环境修复时才安装或修改客户端配置，避免以重载会话阻断已授权的项目工作。

UIKit 包必须面向 iOS Simulator 测试。记录 scheme、destination、通过 / 失败 / 跳过数量及失败摘要。遇到环境故障，区分它与产品回归；验证被阻挡时继续可独立完成的工作，保留明确的未验证项。

## 选择验证范围

- 文档与指令：内容一致性、路径、frontmatter、变更差异；无需运行 App 测试。
- UI：受影响 target 构建与具体操作场景，按用户约定决定是否新增测试。
- 行为或共享契约：能暴露相关回归的现有测试，必要时补充关键路径测试。
- 发布或跨产品变更：按实际发布标准完成所需平台、依赖解析和集成验证。

同一次检查可以覆盖多个验收条件。只有新变更、失败或未解决风险才要求重跑；不要为重复证明同一结论扩大到全量。对未验证范围如实说明。
