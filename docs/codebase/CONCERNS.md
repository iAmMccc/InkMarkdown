# 维护风险与边界

本页只保留当前维护时需要判断的风险，不保留已解决问题流水账。发布验收缺口统一见 [当前状态](../current-status.md)。

- 自定义 inline syntax 与图片不保证完整继承删除线；行为契约见 [扩展语法](../spec/extended-syntax.md)。变更组合语义时，需要能区分正确行为与回归的验证。
- 图片后端拥有资源管理，核心拥有呈现订阅；不能把旧 Store 缓存与调度职责重新放回核心。见 [图片后端指南](../contributor-guide/12-image-backends.md)。
- 流式 renderer、配置语义与 SwiftUI continuity 是共享边界。修改时检查源文本、呈现身份、取消与过期结果之间的关系，避免仅修补某个宿主。
- 测量未知宽度不等于零内容高度；布局回调不得产生重复失效循环。见 [布局测量契约](../contributor-guide/13-layout-measurement-contract.md)。
- 本地缓存、已定义测试与 CI 配置分别不证明远程解析、测试通过或远端任务成功；当前候选须有对应结果。

不以文件行数、旧 TODO 行号或已删除扫描报告推断缺陷。发现新风险时记录触发条件、实际影响和源码入口；缺少证据时标为待核验。
