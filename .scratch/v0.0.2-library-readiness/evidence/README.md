# Evidence Index

本目录只记录当前候选 SHA 的可复现证据。每项记录必须包含时间、commit、工具、scheme、destination、命令或交互步骤，以及通过、失败、跳过或环境阻塞结果。

- `ci-and-consumer.md`：CI、product 隔离、ExampleApp 与消费者构建。
- `api-audit.md`：`0.0.1` 与当前公开 interface 对比及处置。
- `compatibility-and-ui.md`：runtime、iPhone/iPad、ExampleApp 人工矩阵。
- `verification.md`：最终本地测试、审查与远端 CI 汇总。
