# Support

InkMarkdown is a UIKit-first library. This page explains where to look before opening a public, non-sensitive request.

## Start here

- For released `0.0.1`, follow the README examples that import only the `InkMarkdown` product.
- `0.0.2` is unreleased. `InkMarkdownSwiftUI`, `InkMarkdownLaTeX`, and `InkMarkdownMermaid` belong to the current unreleased branch and are not part of the `0.0.1` installation contract.
- Check the [current project status](docs/current-status.md), [FAQ](docs/contributor-guide/06-faq.md), and [rendering specification](docs/spec/README.md) for known behavior and limitations.

## Public questions and reproducible problems

Use the repository's [GitHub Issues](https://github.com/iAmMccc/InkMarkdown/issues) for non-sensitive usage questions, reproducible bugs, and feature proposals. Select the matching issue form when one applies.

Include the smallest useful set of details:

- version or commit, product, device/OS, and Swift/Xcode toolchain;
- Markdown input or a minimal reproduction;
- expected and actual behavior;
- relevant logs with credentials and private data removed.

For contribution or validation questions, read [CONTRIBUTING.md](CONTRIBUTING.md).

## Security-sensitive information

Do not publish credentials, private data, or suspected vulnerability details in a public issue. The repository currently has no private vulnerability reporting channel: no route is documented in the repository, and GitHub private vulnerability reporting was verified as disabled on 2026-09-01. The maintainer decision needed before adding security reporting instructions is recorded in [当前项目状态](docs/current-status.md).
